# Frontend do Livro de Contas

Interface React + Vite. Consulte o [README principal](../README.md) para instalação, execução, configuração, checklist, regras financeiras e notas de segurança.

O fluxo recomendado é `npm run setup` e `npm run dev` na raiz, para iniciar também a API. O build local completo é servido pelo backend após `npm run build` e `npm start`.
